# Third-party console assets vendored into the image at build time.
#
# The developer consoles used to load their JavaScript from a CDN. That put a third party in the
# trust boundary of a route that is public by default, and it made both consoles blank on an
# air-gapped deployment -- which contradicts the reason to self-host reference data at all.
#
# Each asset below is pinned to an exact version and verified against its SHA-256 digest at build
# time, so the bytes in the image are the bytes that were reviewed. A changed upstream file fails
# the build rather than silently shipping.
#
# To upgrade one, change the version in the URL, run:
#     curl -sSLf <url> | shasum -a 256
# and replace the digest. The consoles are developer tools, so an upgrade is a deliberate act.
#
# Columns: <path in the image>  <url>  <sha256>
